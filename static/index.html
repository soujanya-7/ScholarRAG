The ScholarRAG Engineering Architecture

Everything you need to know to master and explain this project in AI engineering interviews.

1. Layout-Aware Parsing & Chunking

Instead of naive character splitting which breaks equations and tables, ScholarRAG parses PDFs page-by-page, preserving section hierarchies, page numbers, and applying recursive splitting with a 120-character overlap.

2. Bi-Encoders vs. Cross-Encoders

Bi-Encoders (FastEmbed BGE) embed query and document separately for lightning fast $O(1)$ vector retrieval. Cross-Encoders (FlashRank) take Query + Document jointly into transformer layers to compute deep token-to-token cross-attention.

3. Reciprocal Rank Fusion (RRF)

Dense vector search produces cosine similarities $\in [0, 1]$, while BM25 produces unbounded scores $[0, \infty)$. RRF combines their rank distributions without fragile score normalization:

$$RRF(d) = \sum_{m \in M} \frac{1}{k + \text{rank}_m(d)}$$

4. HyDE (Hypothetical Doc Embeddings)

Questions are short; documents are long and explanatory. HyDE prompts the LLM to write a hypothetical excerpt first, embedding that answer to land directly inside the document vector cluster.
